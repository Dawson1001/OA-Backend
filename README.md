# **OA System**

### **项目简介**

这是一个个人开发的办公自动化（OA）系统的后端项目，基于Django 5和Django REST Framework构建，采用前后端分离架构。后端通过设计灵活的RESTful接口，为前端提供高效、可靠的数据和业务支持，旨在打造一套轻量且实用的企业基础办公管理解决方案，实现多种办公流程及员工管理的高效处理。

------

### **核心功能**

- 请假申请与审批流程管理
- 通知发布与查阅
- 员工账号激活
- 员工信息管理，添加员工、查看员工详情
- 员工信息批量下载与上传，支持数据批量处理

------

### **特点**

- 使用Redis作为高效的中间缓存层，显著提升系统的数据访问速度和响应性能，减轻数据库压力。
- 采用Celery异步任务队列实现邮件激活等耗时操作的异步处理，提升系统并发能力和用户体验。
- 应用JWT认证机制，保障接口安全，同时保证灵活的身份验证和权限管理。
- 在激活员工账号的过程中，采用加密算法对邮箱信息进行保护，保障用户隐私和数据安全，防止敏感信息泄露。
- 具有高扩展性，支持根据企业业务需求的后续功能扩展和升级。
- 代码结构清晰、模块化设计，易于理解和维护。

------

### **技术栈**

- **后端**：Django 5 + Django REST Framework
- **数据库**：MySQL
- **认证机制**：JWT认证
- **缓存与消息中间件**：Redis
- **异步任务处理**：Celery
